用help()函数查看函数信息
(在ipython中可以用<函数名>?)

## 函数定义

```python
def 函数名(参数):
    ...
        return 参数2
```

- 若无return,则返回none

- pass:什么也不做
- 函数可以返回多个值,相当于返回一个tuple         [[list与tuple]]
```python
return a,b,c
return (a,b,c)      #这两等价
```

## 函数的参数

### 默认参数

```python
def 登记(name,gender,age = 18,city = '贵州'):
    ...
```
- 注意:默认参数要放在后面

### 可变参数

```python
def <函数名>(<tuple或list>):
     ...

<函数名>([1,2,3])
<函数名>((1,2,3,4))

```

等价于
```python
def <函数名>(*<tuple名>)
    #当成tuple用

<函数名> (1,2,3)
```

可以使用   \*list名   把list中的元素作为可变参数传入
