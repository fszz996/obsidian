### Class and Object

class 是一种object的定义,分为两个部分:
**属性** : 对象的数据  **方法**:对象的行为
```java
person p =new person();
```
p是引用对象,理解为指向p的指针

#### 构造方法
方法名与类名相同,用于初始化对象
``` java
public person (String name,int age){
this.name=name;
this.age=age;
}



Person p =new person ("fszz",18);
```

#### 封装
用**private**将对象属性设置,再写**setter**方法来修改private属性

#### 继承
当多个类之间有重复代码,可以使用继承,表示is-a关系
```java
public calss Student extends person{
      //     子类              父类 
}
```
关于访问权限:
- public
- private: 只允许在其声明的类里面访问
- protected:可以在同一包的代码中访问,与子类中访问--使用super.访问

关于继承中的构造方法:
如果父类中存在构造方法,子类应在构造方法的第一句写下  **super('传入的参数')**,  以调用父类的构造方法
如果不写,自动插入super(),如果父类没有无构造方法,则会编译失败

#### override(重写)
父类与子类使用相同的方法名,让子类改变父类的具体实现
可以加入 @override 来让编译器检查父类中有无此方法,如果创建的是新方法会报错

#### 多态
```java
Animal a1 = new cat()
```
子类的对象可以被当做父类类型来使用,在调用函数时会执行子类的版本
在相同的父类的引用,在指向不同的子类对象时,调用同一个被重写的方法, 会产生不同的行为

**notice**:在引用多态时,只能应用父类中有的方法,否则编译会报错

#### 抽象类与抽象方法

```java
abstract calss Animal{
abstract void speak();
}
```
上述定义了一个抽象类和一个抽象方法
抽象类不能直接创建对象,抽象方法只规定了方法的返回值,参数和名称
用于被继承,统一继承的类和方法

#### 接口
```java
interface Swimmale{
void swim();//默认public abstruct型
}

class doge extends animal implements Swimmale,runable{//同时继承与接口,且可以有多个接口

}

Swimmale s = new dog();//用接口来实现多态
```
可以不是同一个父类也能使用多态调用,规定了对象具备的能力,接口可以使用多个
