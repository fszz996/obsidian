### inode
-index node 索引节点

文件名s -> inode -> 数据块

#### inode 内容
1. 文件类型     - d l   (普通文件，dir，软连接)
2. 权限
3. 文件所有者
4. 大小
5. 时间
6. 数据块位置

#### 权限
r        w       x                            -
read  write  excute（可执行）  无权限
4        2        1

eg：-rwxr-xr-x
软连接  文件所有者 同组用户 其他用户   （三个一组）
         user        group    others                      all
